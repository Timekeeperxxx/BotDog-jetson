# 配置项矩阵与参数约定

> **最后更新**：2026-07-23

配置来源分三层：

1. `.env` / 环境变量：由 `backend/config.py` 的 `Settings` 读取，是启动时配置的权威来源。
2. 数据库运行时配置：由 `backend/services_config.py` 的 `DEFAULT_CONFIGS` 初始化到 `system_config`，通过 `/api/v1/config` 管理。
3. 前端构建时配置：`VITE_API_BASE_URL`、`VITE_WHEP_URL` 等。

本文只列维护和联调最常用的配置。完整默认值以 `backend/config.py` 和 `backend/services_config.py` 为准。

视频流水线硬件参数单独存放在 `config/pipeline.env`，由
`scripts/run-pipeline.sh` 和 `botdog-pipeline.service` 共用。

|-----|--------|------|

| `AUTH_ENABLED` | `true` | 是否启用登录鉴权 |
| `AUTH_ADMIN_USERNAME` | `admin` | 初始化管理员用户名 |

| `JWT_SECRET` | `please_change_me_to_a_random_string` | JWT 签名密钥，生产必须修改 |
| `MAVLINK_SOURCE` | `simulation` | `simulation` 或 `mavlink` |
| `SIMULATION_WORKER_ENABLED` | `true` | 是否启用模拟遥测 |

| `UNITREE_NETWORK_IFACE` | `eno1` | Unitree B2 连接网卡 |

## 视频流水线（`config/pipeline.env`）

| Key | 当前值 | 说明 |
|-----|--------|------|
| `CAMERA_RTSP_URL` | `rtsp://192.168.123.108:554/` | Z2 Mini 主摄像头原始 RTSP，免鉴权 |
| `CAM1_INPUT_CODEC` | `h264` | 原始视频编码 |

| `CAM1_WIDTH` / `CAM1_HEIGHT` | `1920` / `1080` | 主画面输出分辨率 |
| `CAM1_FPS` | `30` | 相机冷启动标称帧率；过热时可能降到约 5 fps |
| `CAM1_GOP` | `15` | 30 fps 时约每 0.5 秒一个关键帧 |

相机通过 `enP8p1s0` 直连，本机地址为 `192.168.123.222/24`。流水线发布
`rtsp://127.0.0.1:8554/cam`，前端使用 `http://<主机>:8889/cam/whep`，
AI Worker 继续从本机 `cam` 拉流，避免相机承担多个并发客户端。

Z2-Mini 云台已通过 GCU 私有协议接入 TCP `2332`。前端主视频下方的“相机调节”
按钮可读取角度并执行点动、回中、指定角度、稳定模式、镜头变焦和 OSD 开关。
补光、夜视、对焦和数字变焦切换在当前实机固件上未可靠生效，因此未开放控制。

| `Z2MINI_HOST` | `192.168.123.108` | 云台控制地址 |
| `Z2MINI_CONTROL_PORT` | `2332` | GCU 私有协议 TCP 端口 |

## 运行时配置 API

| 接口 | 说明 |
|------|------|
| `GET /api/v1/config` | 查询 `system_config` 中的配置 |
| `POST /api/v1/config` | 更新配置，写入 `config_change_history` |
| `GET /api/v1/config/history` | 查询配置变更历史 |

`services_config.py` 当前包含以下配置类别：

| category | 说明 |
|----------|------|
| `backend` | 温度、心跳、WebSocket、视频看门狗、安全开关 |
| `hardware` | Unitree 网卡、MAVLink 端点 |
| `frontend_draw` | 前端画面区域绘制样式 |
| `zone` | 黄色区域检测阈值 |
| `storage` | 快照、遥测、录像保留策略 |
| `auto_track` | 自动跟踪参数 |
| `guard` | 驱离模式参数 |
| `nav` | 导航自动跟踪联动参数 |

## 修改原则

- 启动级硬件、路径、鉴权密钥优先放 `.env`。
- 需要后台页面运行时调整的参数放 `system_config`。
- 真机运动相关安全配置不要为方便调试长期关闭。
- 新增配置时同步更新 `backend/config.py`、`services_config.py`、管理后台展示和本文档。

# 雷达、可见光、热成像同步与三维目标融合

## 1. 当前实现边界

后端提供以下软件链路：

1. 从 ROS2 `/livox/lidar` 订阅 `livox_ros_driver2/msg/CustomMsg` 原始雷达点。
2. 复用 AI Worker 已解码的纯可见光帧及目标框，不额外拉取 RTSP。
3. 纯热成像模式复用 AI 帧时间戳；独立热成像视频适配器可调用热成像采样接口。
4. 按设备时间戳进行三路近似同步，同一样本最多消费一次。
5. 使用雷达到可见光外参把雷达点投影到目标框，选取最近有效深度簇并输出三维中心。
6. 使用热成像到可见光单应矩阵输出热成像对应框。

画中画是合成图，不是两路独立原始画面，因此不会作为精确融合输入。

## 2. 启用条件

在 `backend/.env` 配置：

```dotenv
MULTISENSOR_ENABLED=true
MULTISENSOR_CALIBRATION_PATH=./data/multisensor_calibration.json
MULTISENSOR_LIDAR_TOPIC=/livox/lidar
```

不要直接把示例标定文件用于实机。复制
`config/multisensor_calibration.example.json` 后，必须替换为现场测量结果。

三路时间戳必须处于同一时钟域。建议设备和 Jetson 使用 PTP；无法使用 PTP 时，
至少使用 chrony/NTP，并记录每路时间偏差。默认同步窗口为 80 ms，可通过
`MULTISENSOR_SYNC_TOLERANCE_MS` 调整。

## 3. 标定文件

- `visible_intrinsics`：当前分辨率和标定变焦倍率下的可见光内参。
- `lidar_to_visible`：将原始 Livox 坐标转换到 OpenCV 可见光光学坐标的刚体变换。
- `thermal_to_visible_homography`：将热成像像素映射到可见光像素的单应矩阵。
- `thermal_resolution`：计算热成像单应矩阵时使用的原始分辨率。
- `gimbal_reference`：执行联合标定时的云台相对偏航、俯仰和变焦倍率。
- `coordinate_validation`：现场独立测量结果；没有验证时保持 `null`。

当前实现只在云台姿态和变焦接近 `gimbal_reference` 时输出坐标。云台转动后静态外参
不再成立，服务会明确拒绝输出，而不是继续给出错误坐标。

可通过管理员/操作员接口写入并原子替换标定：

```text
PUT /api/v1/multisensor/calibration
```

## 4. 接口

| 接口 | 权限 | 用途 |
|---|---|---|
| `GET /api/v1/multisensor/status` | viewer | 三路新鲜度、同步时间差、标定和 5 cm 验证状态 |
| `GET /api/v1/multisensor/calibration` | viewer | 当前标定内容 |
| `PUT /api/v1/multisensor/calibration` | operator | 校验并原子更新标定 |
| `POST /api/v1/multisensor/samples/thermal` | operator | 独立热成像适配器登记帧时间戳 |
| `GET /api/v1/multisensor/targets` | viewer | 最近一组融合目标坐标 |

热成像采样接口的 `timestamp` 必须是采集时刻的设备时间，不能用上传请求到达时刻代替。

## 5. 三维输出

每个融合目标包含：

- 可见光目标框和热成像对应框；
- 目标类别、置信度和跟踪 ID；
- Livox 坐标系三维中心 `lidar_xyz_m`；
- 可见光光学坐标系三维中心 `camera_xyz_m`；
- 目标距离、有效点数和深度离散度；
- 三路同步 bundle ID 和时间戳。

目标框内的雷达点会按深度间隙分簇，优先选择最近且点数达到
`MULTISENSOR_MIN_TARGET_POINTS` 的簇，避免把目标后方墙面作为目标距离。

## 6. 5 cm 验证

软件输出坐标不代表已经满足 5 cm。现场至少选择不同距离、水平位置和高度的固定标志点，
使用独立测量设备得到真值，并记录每个点的三维误差。只有 `rmse_m` 和
`max_error_m` 都不超过 `0.05` 时，状态接口中的
`coordinate_accuracy_verified` 才会为 `true`。

验证不合格时依次检查：

1. PTP/NTP 时间偏差和运动目标速度；
2. 云台是否处于标定姿态、变焦是否一致；
3. 可见光内参和畸变校正；
4. 雷达到相机外参及设备安装刚性；
5. 目标框内点云是否混入地面、围栏或背景墙。

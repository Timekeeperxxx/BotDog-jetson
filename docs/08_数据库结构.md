# BotDog 数据库结构（SQLite）

> **最后更新**：2026-07-02

当前数据库结构以 `backend/models.py` 的 SQLAlchemy ORM 模型为准，应用启动和 `scripts/init_db.py` 会创建缺失表。旧的 `db/schema.sql` 不再作为权威来源。

默认数据库路径：

```text
sqlite+aiosqlite:///./data/botdog.db
```

## 表清单

| 表 | ORM 模型 | 用途 |
|----|----------|------|
| `users` | `User` | 登录账号、角色、启停状态、token 版本 |
| `inspection_tasks` | `InspectionTask` | 巡检会话/任务生命周期 |
| `telemetry_snapshots` | `TelemetrySnapshot` | 巡检任务关联的遥测快照 |
| `anomaly_evidence` | `AnomalyEvidence` | AI 告警、抓拍、证据记录 |
| `operation_logs` | `OperationLog` | 操作与审计日志 |
| `config` | `ConfigEntry` | 早期配置表，保留兼容 |
| `system_config` | `SystemConfig` | 当前配置管理 API 使用的运行时配置表 |
| `config_change_history` | `ConfigChangeHistory` | 配置变更历史 |
| `focus_zones` | `FocusZone` | 视频画面中的关注区域 polygon |
| `session_known_targets` | `SessionKnownTarget` | 单次巡检中的已知目标标记 |
| `video_sources` | `VideoSource` | 视频源配置 |
| `recordings` | `Recording` | 录像记录 |
| `network_interfaces` | `NetworkInterface` | 网口配置 |

## 关键关系

- `inspection_tasks` 1:N `telemetry_snapshots`，任务删除时遥测快照级联删除。
- `inspection_tasks` 1:N `anomaly_evidence`，任务删除后证据保留，`task_id` 置空。
- `inspection_tasks` 1:N `operation_logs`，任务删除后日志保留，`task_id` 置空。
- `session_known_targets` 只表示一次巡检任务内的人工标记，不是跨任务身份白名单。

## 重要约束

| 表 | 约束 |
|----|------|
| `users` | `role` 只能为 `viewer/operator/admin`；`enabled`、`must_change_password` 为 0/1 |
| `inspection_tasks` | `status` 只能为 `running/completed/stopped/failed` |
| `telemetry_snapshots` | `battery_remaining_pct` 为空或 0-100 |
| `anomaly_evidence` | `severity` 支持 `INFO/WARN/WARNING/ERROR/CRITICAL`；`confidence` 为空或 0-1 |
| `operation_logs` | `level` 支持 `INFO/WARN/ERROR/CRITICAL`；`module` 支持 `BACKEND/UI/MEDIA/EDGE` |
| `config` | `value_type` 支持 `string/int/float/bool/json`；`is_hot_reload` 为 0/1 |

## 配置 Seed

配置项默认值由 `backend/services_config.py` 的 `DEFAULT_CONFIGS` 提供，首次初始化或缺项补齐时写入 `system_config` 表。配置文档见 [07_配置项矩阵.md](07_配置项矩阵.md)。

## 初始化与检查

```bash
cd ~/Code/Project/BOTDOG/BotDog
source .venv/bin/activate
PYTHONPATH=. python scripts/init_db.py
```

常用检查：

```bash
sqlite3 data/botdog.db ".tables"
sqlite3 data/botdog.db "select username, role, enabled from users;"
sqlite3 data/botdog.db "select key, value, value_type from config order by key;"
```

## 迁移注意

当前项目没有独立 Alembic 迁移目录。新增字段或新增表时应同步完成：

1. 更新 `backend/models.py`。
2. 更新初始化/补齐逻辑。
3. 为旧数据库补充兼容脚本或启动时补齐逻辑。
4. 更新本文档和相关接口文档。

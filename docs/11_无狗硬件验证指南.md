# 无机器狗硬件验证指南

> **最后更新**：2026-07-02

本文用于在没有 Unitree B2 本体的情况下验证 BotDog 的前后端、登录、数据库、视频、AI、证据、配置和导航页面。真实运动、真实遥测和真机安全验证仍需要机器狗。

## 可验证范围

| 模块 | 无机器狗是否可验证 | 说明 |
|------|--------------------|------|
| 登录与权限 | 可以 | 使用默认管理员账号或 `.env` 配置账号 |
| 前端主控台 | 可以 | 访问 `/`，查看视频、遥测、事件、证据面板 |
| 管理后台 | 可以 | 访问 `/admin`，验证用户、日志、配置、设备与视频页面 |
| 模拟遥测 | 可以 | `MAVLINK_SOURCE=simulation` |
| Web 手动控制 API | 可以 | 使用 `CONTROL_ADAPTER_TYPE=simulation`，只验证请求和仲裁，不产生真实运动 |
| 急停 | 可以 | 验证状态变化和接口返回 |
| 配置管理 | 可以 | 验证 `/api/v1/config` 与变更历史 |
| 证据与录像 | 部分可以 | 抓拍/录像需要有效视频流；无摄像头时只能验证接口错误处理 |
| WHEP 视频 | 需要摄像头或测试 RTSP 源 | 使用 `scripts/run-pipeline.sh` |
| PCD 导航页面 | 可以 | 可以验证点云预览、导航点和任务数据；ROS2 真实执行需要对应环境 |
| 真机运动 | 不可以 | 需要 Unitree B2 和正确网卡/DDS 环境 |

## 推荐配置

`backend/.env` 至少确认：

```ini
MAVLINK_SOURCE=simulation
SIMULATION_WORKER_ENABLED=true
CONTROL_ADAPTER_TYPE=simulation
SAFETY_BLOCK_MOTION_WHEN_DISCONNECTED=false
AI_ENABLED=false
AUTH_ENABLED=true
```

如果有 RTSP 摄像头或 MediaMTX 测试流，可以把 `AI_ENABLED=true`，并设置：

```ini
AI_RTSP_URL=rtsp://127.0.0.1:8554/cam
AI_MODEL_PATH=models/helmet.engine
```

## 启动步骤

```bash
cd ~/Code/Project/BOTDOG/BotDog
source .venv/bin/activate
PYTHONPATH=. python scripts/init_db.py
PYTHONPATH=. python run_backend.py
```

另开终端启动前端开发服务器：

```bash
cd ~/Code/Project/BOTDOG/BotDog/frontend
npm run dev
```

访问：

```text
http://localhost:5174
http://localhost:5174/admin
http://localhost:5174/nav-patrol.html
```

生产构建验证：

```bash
cd frontend
npm run build
cd ..
PYTHONPATH=. python run_backend.py
# 访问 http://localhost:8000
```

## 验证清单

| 项目 | 验证方法 |
|------|----------|
| 健康检查 | `curl http://localhost:8000/api/v1/system/health` |
| 登录 | 浏览器访问 `/login`，使用管理员账号登录 |
| 当前用户 | `GET /api/v1/auth/me` 应返回用户信息 |
| 遥测 WebSocket | 浏览器控制台应建立 `ws://localhost:8000/ws/telemetry` |
| 事件 WebSocket | 浏览器控制台应建立 `ws://localhost:8000/ws/event` |
| 模拟遥测 | 主控台姿态、电池、温度等数据持续刷新 |
| 手动控制 | 在模拟适配器下发送控制命令，后端返回 ack 且不触发真实运动 |
| 急停 | 触发 `/api/v1/control/e-stop` 后控制命令应被安全逻辑阻止 |
| 配置 | 管理后台“系统配置”可读取配置并写入变更历史 |
| 日志 | 管理后台“日志中心”可查看审计日志和运行日志 |
| 证据 | `GET /api/v1/evidence` 返回列表；有视频源时可验证抓拍 |
| 导航页面 | `/nav-patrol.html` 可打开并读取 PCD 场景/导航点接口 |

## 视频验证

有摄像头或 RTSP 源时：

```bash
bash scripts/run-pipeline.sh
curl http://127.0.0.1:8889/v3/paths/list
```

浏览器访问主控台后，前端会按当前 hostname 生成 WHEP 地址：

```text
http://<host>:8889/cam/whep
```

没有摄像头时，不要把视频失败当作系统失败；此时只能验证非视频功能和视频错误提示。

```bash

```

若机器没有 ROS2、Unitree SDK、模型或摄像头，部分集成测试可能需要按本机环境筛选运行；失败时先看错误是否来自真实硬件依赖。

## 常见问题

**后端启动后控制接口返回断链保护**

无机器狗验证时使用：

```ini
CONTROL_ADAPTER_TYPE=simulation
SAFETY_BLOCK_MOTION_WHEN_DISCONNECTED=false
```

真机部署不要关闭断链保护。

**视频不显示**

确认 `scripts/run-pipeline.sh` 正常运行、`config/mediamtx.yml` 生效、`8889` 端口可访问，并检查 `AI_RTSP_URL` 或前端 WHEP URL 是否指向同一个 MediaMTX 路径。

**登录失败**

重新运行 `PYTHONPATH=. python scripts/init_db.py` 补齐默认用户，或检查 `AUTH_ADMIN_USERNAME` / `AUTH_ADMIN_PASSWORD`。首次部署应立即修改默认密码和 `JWT_SECRET`。

**导航接口可打开但无法真实导航**

这是无 ROS2 环境的预期结果。PCD 预览、导航点和任务数据可验证；`/initialpose`、TF、global path、导航启动等需要 ROS2 和导航节点在线。

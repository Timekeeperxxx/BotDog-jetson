# 姿态摄像头试验台

在 Jetson 仓库根目录启动：

```bash
.venv/bin/python -m backend.pose_lab
```

在有摄像头的电脑建立转发，保持连接：

```bash
ssh -N -L 127.0.0.1:8011:127.0.0.1:8011 jetson@192.168.8.33
```

在该电脑的浏览器访问 http://localhost:8011 ，点击“开启摄像头”并允许权限。
优先请求前置摄像头。停止或切到后台会释放摄像头，重新开始会清零动作历史。
手机不能使用电脑的 localhost；手机访问需要另行配置可信 HTTPS 和访问控制。

测试复用板子的 `UltralyticsPoseDetector`、`PoseEventEngine` 与当前 `POSE_*` 参数，
独立加载模型；额外占用一次模型内存和推理算力。服务仅监听回环地址，一次允许一个测试会话。
不发送机器狗控制命令，不广播正式告警，不保存视频或抓拍。

支持疑似攀爬/翻越、胸口及以上双手活动的疑似破坏、蹲伏、倒地、停留。
这不是围栏结构变化检测；规则分也不是校准后的概率。
画面为 640×480 等比缩放留边，镜像只影响显示。
“传输＋处理”从浏览器发送帧到收到结果计时，不包含相机曝光延迟；首帧包含模型初始化。

验证：`.venv/bin/python -m pytest tests/test_pose_lab.py tests/test_pose_detection.py -q`

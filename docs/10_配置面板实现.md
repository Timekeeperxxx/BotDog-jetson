# 配置管理实现说明

> **最后更新**：2026-07-02

BotDog 当前配置管理由后端配置服务、数据库配置表、前端主控台配置弹窗和管理后台共同组成。本文只描述当前实现，不再保留早期“配置面板实施总结”的阶段记录。

## 代码位置

| 位置 | 说明 |
|------|------|
| `backend/config.py` | 启动级 Settings，读取 `.env` 和环境变量 |
| `backend/models_config.py` | `system_config` 与 `config_change_history` ORM 模型 |
| `backend/services_config.py` | 默认配置 seed、读取、校验、更新、热更新 |
| `backend/api/routes/config.py` | `/api/v1/config` 路由 |
| `frontend/src/hooks/useConfig.ts` | 前端配置 API hook |
| `frontend/src/components/modals/ConfigModal.tsx` | 主控台配置弹窗 |
| `frontend/src/admin/pages/AdminConfigPage.tsx` | 管理后台配置页面 |

## 数据流

```text
.env / 环境变量
  -> backend/config.py Settings
  -> services_config.DEFAULT_CONFIGS
  -> system_config
  -> GET /api/v1/config
  -> ConfigModal / AdminConfigPage

用户修改配置
  -> POST /api/v1/config
  -> ConfigService.update_config()
  -> system_config + config_change_history
  -> 可热更新项同步到运行中 settings / 服务状态
```

## API

| 接口 | 说明 |
|------|------|
| `GET /api/v1/config` | 查询配置项，支持按 category 过滤 |
| `POST /api/v1/config` | 更新单个配置项 |
| `GET /api/v1/config/history` | 查询配置变更历史 |

更新请求示例：

```json
{
  "key": "thermal_threshold",
  "value": "70.0",
  "changed_by": "admin",
  "reason": "admin_config_page"
}
```

## 配置类别

| category | 示例 | 说明 |
|----------|------|------|
| `backend` | `thermal_threshold`、`heartbeat_timeout` | 后端运行参数 |
| `hardware` | `unitree_network_iface`、`mavlink_endpoint` | 硬件链路参数 |
| `frontend_draw` | `zone_draw_*` | 前端区域绘制样式 |
| `zone` | `zone_yellow_*`、`zone_min_area_px` | 黄色区域检测阈值 |
| `storage` | 快照、遥测、录像保留策略 | 存储清理参数 |
| `auto_track` | `auto_track_*` | 自动跟踪参数 |
| `guard` | `guard_*` | 驱离模式参数 |
| `nav` | `nav_auto_track_*` | 导航自动跟踪联动参数 |

完整配置矩阵见 [07_配置项矩阵.md](07_配置项矩阵.md)。

## 权限与审计

- 配置接口受登录鉴权保护。
- 管理后台按用户角色控制入口可见性。
- 每次配置更新都会写入 `config_change_history`，并由相关业务路径写入审计日志。
- 生产环境必须修改默认管理员密码和 `JWT_SECRET`。

## 热更新边界

配置项的 `is_hot_reloadable` 只表示后端允许运行时更新该参数。硬件链路、模型路径、进程级路径、ROS2 环境变量等启动级配置仍建议通过 `.env` 修改后重启服务。

典型热更新项：

- 温度阈值。
- 视频看门狗超时。
- 安全断链保护开关。
- 黄色区域检测阈值。
- 自动跟踪速度、死区和超时。
- 驱离模式视觉伺服参数。

典型需重启项：

- 数据库 URL。
- 后端监听地址/端口。
- JWT 密钥。
- 大部分 ROS2 环境与 Unitree DDS 环境。
- 模型文件切换后的推理进程重建。

## 维护要求

新增配置时需要同步：

1. `backend/config.py` 中的 Settings 默认值。
2. `backend/services_config.py` 中的 `DEFAULT_CONFIGS`、校验和热更新逻辑。
3. 前端展示或管理后台表单。
4. [07_配置项矩阵.md](07_配置项矩阵.md)。

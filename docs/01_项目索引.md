## 速查命令

```bash
# 后端
source .venv/bin/activate
PYTHONPATH=. python scripts/init_db.py
PYTHONPATH=. python run_backend.py

# 视频流水线
bash scripts/run-pipeline.sh

# 前端开发
cd frontend
npm run dev

# 常用验证
python -B -m pytest
cd frontend && npm run build
```

## 清理规则

- `docs/` 只保留仍能指导当前代码运行、部署、联调或验收的文档。
- 已实现的开发路径、一次性搜索报告、审阅稿和重复计划稿会删除，不再从索引引用。
- 删除文档前需要确认没有 README、代码注释或保留文档继续引用该文件。

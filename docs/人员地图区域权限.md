# 地图区域级别与人员通行权限

按用户确认的规则，区域名称、区域级别和人员权限级别分别设置。操作台导航地图负责区域，人脸档案负责人员权限，不再逐区勾选人员。判权使用机器人所在地图区域，无需相机标定，也不估计人员脚下坐标。

## 等级规则

数字越小权限越高，满足“人员权限级别 ≤ 区域级别”才允许通行。

| 人员权限级别 | 允许进入的区域级别 |
|---|---|
| 1级 | 1、2、3级 |
| 2级 | 2、3级 |
| 3级 | 3级 |

区域1、区域2是名称，不决定其级别。多个区域可以使用相同级别。机器人同时处在多个区域时，对每个区域执行同一规则，效果等同于按最严格的级别判断。3级人员出现在机器人所在的1级区域时，连续有效确认后产生 `E_MAP_ACCESS_DENIED`，即使此人已经登记。

未登记、身份确认失败或已停用的人员不取得区域通行权；身份处于 `pending` 时不累计告警确认次数。原有人员迁移后权限级别为空，在人脸编辑窗口明确分配后生效，不自动授予任何级别。可将人员级别重新设为“未设置”，撤销其受控区域通行资格。

机器人定位过期、坐标系不匹配、地图不明确或处在区域边界待判带时显示无法判定，不将不确定位置记录成越权事实。机器人明确在全部已配置区域之外时，沿用原人员识别策略。旧区域如未设置级别则返回无法判定，需编辑区域后保存其级别。

## 设置入口

管理员进入操作台导航页面，在右侧“导航点 / 围栏 / 区域”标签组点击“区域”。选择地图后，可新建区域，依次点选至少三个地图顶点，填写区域名称、选择1/2/3级并保存。列表支持编辑名称、级别、启停和边界，支持删除确认。地图显示区域轮廓、填充、名称和级别；顶点来自原地图，未简化点云。不同地图的区域互相隔离，切换地图会清除未保存的区域草稿。

后台“人员识别库”的新增和编辑窗口设置“人员权限级别”，列表同时显示当前级别。人员级别与登录账号的管理员、操作员、查看者角色是两套不同信息；区域及人员权限只能由管理员修改，其他已登录账号可在导航地图查看区域。

打开区域编辑面板时，地图点击用于选区域顶点，停止使用导航点、围栏和重定位选点模式；键盘移动控制不接收编辑期间的按键。建图过程中不允许编辑已保存场景的区域。

## 运行和数据

区域多边形使用地图水平坐标 `(x,y)` 判断内外，保留各顶点高度用于展示。默认边界待判带为0.15米，可在表单调整；这是软件设计参数，不是实测定位误差。机器人位置历史与视频帧接收时间匹配，允许时间差为0.35秒；超过1秒的视频帧不作区域判权。这些约束不代表现场识别率或定位精度。

数据库以新增可空 `access_level` 列迁移人员和区域，不覆盖人员姓名、人脸特征、历史证据或地图顶点。旧逐区授权表和标定表保留结构兼容，当前判权不读取它们；旧勾选名单不自动换算为等级。保存区域级别、修改人员级别、停用或删除人员后立即更新运行快照。

状态接口返回 `authorization_method=hierarchical_access_level`、`level_rule=person_level <= region_level` 和 `calibration_required=false`。区域接口保留 `/api/v1/map-access/zones`，写入时要求明确的整数级别1/2/3。人员接口增加可空 `access_level`。

## 告警与验证

告警保留抓拍、入库、事件广播和显示计时链路，消息明确写出机器人所在区域及级别、人员姓名及其权限级别。`access_context` 保存区域级别、人员级别、要求级别、拒绝区域、机器人位置、定位来源与时间及权限版本。相同人员和区域执行重复告警间隔，修改人员或区域权限后重新评价，重启后仍依据既有证据恢复重复间隔。

自动测试使用软件构造坐标和临时数据库，覆盖3×3等级组合、已登记越权、未分配权限、最严格重叠区域、机器人跨区、地图切换、定位失效、权限修改即时生效、迁移后原记录保留、重启重载、管理接口鉴权及告警证据。前端验证导航画区与级别保存、场景切换丢弃过期响应、人脸新增及编辑权限和非管理员只读。

这些是软件功能测试，不是正式识别率或现场试次结果。视频接入后，再按正式方案记录各区域下不同权限人员的实际识别及报警结果。
